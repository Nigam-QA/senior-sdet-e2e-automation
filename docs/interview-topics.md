# Senior SDET discussion prompts

1. Explain the framework architecture and why you chose Page Object Model.
2. How does ThreadLocal WebDriver support parallel execution? What are its risks?
3. How do you prevent flaky tests and distinguish product defects from test defects?
4. How would you scale from 100 to 10,000 UI tests?
5. How would you manage test data across parallel API tests?
6. How would you validate API contracts and backward compatibility?
7. How would you decide which tests run at PR time versus nightly regression?
8. What quality metrics would you report to engineering leadership?

Be ready to explain trade-offs, failure modes, maintainability and measurable impact.
